# Project — Demo Notes

## Goal

Demonstrate an AI workbench that remembers context without polluting human-authored notes.

## Workflow

1. Install the workbench.
2. Save durable memory.
3. Update hot context.
4. Start a new session.
5. Run `/brain` to recover context.
