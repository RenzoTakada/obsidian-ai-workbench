# Prompt: Implement with OpenClaw

Read this repository and implement the Obsidian AI Workbench pattern for OpenClaw.

Requirements:

1. Ask for the Obsidian vault path if needed.
2. Create `_AI/` or `_OpenClaw/` inside the vault.
3. Copy/adapt `templates/openclaw/` into that folder.
4. Set the OpenClaw workspace to that folder.
5. Keep the parent vault as human-authored space.
6. Do not access outside the AI workbench unless explicitly authorized.
7. If authorized, configure Ollama embeddings for `memorySearch`.
8. Reindex memory and test search.
9. Explain the final architecture.
