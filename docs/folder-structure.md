# Folder Structure

This is a recommended starting point. Adapt it to your own workflow.

## Vault root

```text
MyVault/
  Inbox/
  Literature Notes/
  Permanent Notes/
  Projects/
  Topics/
  Resources/
  _AI/
```

## Human folders

### `Inbox/`
Raw captures: links, quick notes, quotes, ideas.

### `Literature Notes/`
Notes about things you read/watch/listen to.

### `Permanent Notes/`
Evergreen notes written in your own words.

### `Projects/`
Human-owned projects and project thinking.

### `Topics/`
Maps of content, index notes, topic pages.

### `Resources/`
Reference material.

## AI workbench

```text
_AI/
  Inbox/
  Outputs/
  Logs/
  Memory/
  Sessions/
  Projects/
  Specs/
  Skills/
  Templates/
  Decisions/
  Briefings/
  Maintenance/
```

### `_AI/Inbox/`
Raw material for the AI to process.

### `_AI/Outputs/`
Drafts and deliverables produced by the AI.

### `_AI/Logs/`
Operational logs.

### `_AI/Memory/`
Durable memory for the AI.

### `_AI/Sessions/`
Chronological records of work sessions.

### `_AI/Projects/`
AI-managed project workspaces.

### `_AI/Specs/`
PRDs, implementation plans, technical specs.

### `_AI/Skills/`
Reusable procedures.

### `_AI/Templates/`
Reusable templates.

### `_AI/Decisions/`
Decisions and rationale.

### `_AI/Briefings/`
Reference briefings and databases.

### `_AI/Maintenance/`
Audits, cleanup notes, health checks.
