# Codex + Obsidian

Codex can use an Obsidian vault as a Markdown workspace.

## Recommended setup

Use `_AI/` as the Codex workbench.

```text
MyVault/
  Permanent Notes/
  Projects/
  _AI/
    AGENTS.md
```

## Boundary instruction

Put the boundary in `AGENTS.md`:

```text
Inside _AI/: work freely.
Outside _AI/: ask before reading or modifying files.
Do not write permanent notes for the human.
```

## Best use cases

- creating specs;
- maintaining logs;
- generating drafts;
- creating project plans;
- searching and summarizing authorized notes.
