# AGENTS.md — OpenClaw Workbench

This folder is the OpenClaw workbench inside a human-owned Obsidian vault.

## Boundary

- Inside `_OpenClaw/`: OpenClaw may work autonomously unless told otherwise.
- Outside `_OpenClaw/`: ask before reading, creating, editing, moving, or deleting files.
- Do not access `_Claude/`, `_Codex/`, or human-authored notes unless explicitly authorized.
- Do not write permanent notes on behalf of the human.

## Memory

- `MEMORY.md` — curated memory index.
- `Memory/` or `memory/` — durable indexed memory.
- `Sessions/` — chronological session records.
