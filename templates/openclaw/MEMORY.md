# MEMORY.md — AI Workbench Memory Index

This folder is the AI workbench inside an Obsidian vault.

## Structure

- `Memory/` — durable indexed memory.
- `Sessions/` — chronological session logs.
- `Outputs/` — AI-generated drafts and deliverables.
- `Decisions/` — decisions and rationale.
- `Maintenance/` — audits and cleanup.

## Boundary

The parent vault is human-authored space. Ask before accessing or modifying it.
