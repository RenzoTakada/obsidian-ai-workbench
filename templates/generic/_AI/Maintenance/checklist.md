# Maintenance Checklist

Run this review weekly (light) and monthly (full).

A second brain only gains value over time if you maintain it.
More files ≠ more intelligence. Unmaintained notes become noise.

---

## Weekly — Light Review (15–30 min)

### Outputs
- [ ] Review new files in `Outputs/`
- [ ] Delete drafts that are no longer useful
- [ ] Move approved outputs to their final destination (your notes or a project folder)

### Sessions
- [ ] Scan `Sessions/` for the past week
- [ ] Identify decisions or knowledge worth promoting to `Memory/`
- [ ] Delete session logs older than 30 days (or archive them)

### Inbox
- [ ] Process everything in `Inbox/`
- [ ] Route each item: handle it, delegate it to the AI, or delete it

---

## Monthly — Full Review (1–2 hours)

### Memory
- [ ] Read through all files in `Memory/`
- [ ] Remove or update stale entries (things that are no longer true)
- [ ] Add new durable knowledge from recent sessions
- [ ] Check that the `Memory/MEMORY.md` index is accurate

### Decisions
- [ ] Review `Decisions/` for the past month
- [ ] Mark decisions that have been implemented or superseded
- [ ] Archive resolved decisions

### Skills
- [ ] Review `Skills/` for commands and automations
- [ ] Remove skills that are no longer used
- [ ] Update skills that have become outdated

### Specs and Projects
- [ ] Review active specs in `Specs/`
- [ ] Close out completed project files
- [ ] Archive specs for finished work

### Logs
- [ ] Archive or delete `Logs/` older than 60 days
- [ ] Keep only logs that contain information not captured elsewhere

---

## Promotion Checklist

Before promoting AI output to your permanent notes:

- [ ] Have you read and understood the full output?
- [ ] Does it reflect your thinking, not just the AI's?
- [ ] Have you rewritten it in your own words?
- [ ] Does it connect to existing knowledge in your vault?
- [ ] Are you confident it is accurate?

> AI output becomes human knowledge only after the human reviews and rewrites it.

---

## Prune Aggressively

When in doubt, delete. Ask:

- Would I look for this file in the next 3 months?
- Does this file help the AI produce better output, or is it just taking up space?
- Is this information already captured in `Memory/` in a better form?

If the answer to all three is no, delete it.
