# Workbench Commands

These commands are behavior contracts. Agents with slash-command support can map them to native commands; other agents can treat them as natural-language intents.

- `/brain` — load memory, hot context, latest session, inbox, and briefings.
- `/context` — summarize current context without changing files.
- `/save` — route information to memory, outputs, sessions, decisions, specs, inbox, or hot context.
- `/review-memory` — audit memory and propose cleanup.
- `/spec` — create a spec-first implementation proposal.
